# Fundamentals Master Repository

This repository serves as a comprehensive archive of coursework materials accumulated throughout a Bachelor's degree program, focusing on fundamental concepts in computer science and related fields.

## Repository Contents

The repository is organized into folders corresponding to various academic subjects. Each folder contains a collection of relevant materials, including assignments, source code, notes, and project files.

### Course Subjects Included:

* **Algorithms and Data Structures:** Implementations, assignments, and notes related to core data structures and algorithms.
* **C and C++ Programming:** Foundational programming exercises, assignments, and code examples in C and C++.
* **Databases and Web Services:** Materials covering database design (SQL, ER/EER diagrams, normalization), web service architecture, protocols (XML, RDF), NoSQL, and related technologies (PHP, HTML/CSS/JS). Includes a significant web project.
* **Data Structures and Processing (Python):** Assignments and notes focusing on data manipulation, analysis, and visualization using Python libraries (e.g., Pandas, NumPy) in Jupyter Notebooks. Covers topics like data cleaning, wrangling, and time series analysis.
* **Introduction to Computer Science:** Assignments and code examples covering introductory CS concepts, potentially including functional programming (Haskell) and basic algorithms.
* **Introduction to Data Science:** Code examples, notes, and tutorials (Jupyter Notebooks) covering foundational data science concepts, Python libraries (NumPy, Matplotlib, Pandas, Scikit-learn), and basic machine learning.
* **Robotics:** Python code, problem sets, and library files related to robotics concepts like spatial transforms, kinematics, locomotion, and localization.
* **Robotics and Intelligent Systems Lab:** Lab work and projects involving ROS (Robot Operating System), including package creation, nodes (Python/C++), topics, services, and actions.

### Types of Materials:

* **Source Code:** Examples, assignments, and projects written in various languages including C, C++, Python, Haskell, SQL, PHP, HTML, CSS, and JavaScript.
* **Assignments & Lab Work:** Problem descriptions (PDFs), solutions, and associated code files.
* **Jupyter Notebooks:** Interactive notebooks for data science tasks, analysis, and visualizations.
* **Notes & Documentation:** Markdown files (`.md`), text files (`.txt`), and PDFs containing notes, explanations, and documentation.
* **Configuration Files:** Files for build systems, environments, or specific tools (e.g., `CMakeLists.txt`, `package.xml`, `docker-compose.yaml`).
* **Data Files:** Sample datasets and input files used in assignments and projects (e.g., `.csv`, `.tsv`, `.json`, `.txt`).

This repository represents a detailed record of the practical exercises, theoretical understanding, and project work undertaken during the Bachelor's program.
